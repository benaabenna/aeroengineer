# aeroengineer

A clean and practical Python package for aeronautical engineering calculations.

## Features

- Standard atmosphere properties up to 86 km altitude (ISA)
- Common air/gas dynamics calculations (Mach number, isentropic ratios, etc.)
- SI units by default
- Support for scalar values and NumPy arrays for efficient vectorized calculations
- Simple, intuitive Pythonic API
